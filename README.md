# The Excuse My Agent Gave Me

An AI agent misses a deadline after reading all 312 of Sarah's emails to find it, runs out of context on the last one, and confidently sends the finished work to Dave instead. A tiny Python program that writes this excuse, exactly as given, to `/output/entry.txt`.
